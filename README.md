# 평등의 나라 · 취풍 무협전

양성평등 학습지(존중 · 보호 · 자유 · 용기 · 연대)를 바탕으로 만든 **코믹 무협 도트 RPG**입니다.
기존 「평등의 나라 · 바람길 원정」을 이어받아, 고전 동양풍 JRPG처럼 **사이드뷰 턴제 전투 · 초상화 대화창 · 동료 합류 · 칩튠 음악**으로 다시 만들었습니다.

## 실행
- 온라인: Vercel 배포 주소에서 바로 플레이
- 오프라인: `평등의나라_취풍무협전.html` 파일 하나를 Chrome/Edge로 열기 (폰트·코드 모두 내장, 교사용 메뉴 포함·학생용 링크는 웹 주소에서만)
- 우리 반 연동판: 배포 주소의 `/class.html` (교사 문제 실시간 반영, 인터넷 필요)
- 소스: `index.html` + `style.css` + `js/` + `assets/` (정적 파일, 빌드 불필요)

## 조작
- 이동: 방향키 / WASD, 또는 바닥을 클릭·터치
- 대화·조사: Space / Enter · 가방: I · 회복약: 1 · 수련 수첩: J · 소리: M
- 전투: ↑↓←→ 선택, Space/Enter 결정, 숫자키 바로 선택, Esc 뒤로

## 장별 임무 (모두 다른 방식)
| 장 | 고을 | 임무 | 특징 |
|---|---|---|---|
| 1 | 존중의 마을 | 칭찬 편지 5장 모으기 → 도사님께 전달 | 울타리 정원·강 건너·집 뒤 탐색 |
| 2 | 비밀의 숲 | 어둠의 미로에서 열쇠 조각 3개 찾기 | 주변만 보이는 시야, 반딧불 등불로 시야 확장 |
| 3 | 자유의 들판 | 바위 밀기 퍼즐로 갇힌 친구 3명 구출 | 꽃자리에 바위 올리기, 팻말로 되돌리기 |
| 4 | 용기의 다리 | 감시꾼을 피해 종 3개를 순서대로 울리기 | 노란 시야, 풀숲에 숨기, 들키면 전투 |
| 5 | 평등의 성 | 그림자 장수 4명을 물리치고 열쇠 4개 | 지난 고을 복습 문제 |

임무 다음에는 공통으로 **비석 → 외줄 수련 → 보스 → 성문** 순서입니다.

## 전투
- 차례가 된 동료가 행동: **공격**(무기) · **필살기**(문제, 정답이면 큰 피해) · **기술**(기력 소모) · **도구** · **방어** · **도망**
- 기술: 바람 「회오리베기」(전체 공격) · 보미 「꿰뚫는 화살」(보호막 관통) · 곰돌 「곰돌 방패」(피해 감소+회복)
- 적은 여러 마리가 함께 나오고, 강공격 예고·도구 훔치기·부하 부르기·호루라기 등을 사용
- 미니게임: **동체시력 게임**(섞이는 그릇 속 구슬 따라보기) · **타이밍 막기**(강공격 방어) · **주문 따라 하기**(화살표 순서 기억) · **힘겨루기**(연타)
- 보스·그림자 장수는 **보호막**이 있어 정답 필살기로만 깨짐 (학습 요소 유지)
- 무기는 상자·친구 선물로, 도구는 상자·전리품·냥냥 상인에게서 얻음

## 외줄 수련 (장마다 1회, 보스 결계를 푸는 액션 미니게임)
장대 위에서 **←→ 균형**(기울어진 반대쪽!) · **Space 점프** · **↑ 빠르게** · **↓ 천천히/웅크리기** · Esc 일시정지
| 장 | 새로 추가되는 시련 |
|---|---|
| 1 | 끊어진 장대, 굴러오는 통, 까마귀(웅크리기) |
| 2 | + 도깨비불, 미끄러운 구간, 낙석(그림자 보고 속도 조절) |
| 3 | + 돌풍, 좌우 반대 안개, 출렁다리, 뒤쫓는 먹구름 |
| 4 | + 침묵의 안개, 좁은 장대, 더 빠른 먹구름 |
| 5 | 모든 시련 동시 등장 |
- 실패할수록 쉬워지고, 두 번 실패하면 도사님 도움으로 통과 가능

## 교사용 메뉴 (머리글의 「교사용」 버튼)
처음 비밀번호는 **1234** — 「설정」 탭에서 꼭 바꿔 주세요. (학생이 실수로 들어오지 않게 하는 간단한 잠금이며 보안 기능은 아닙니다)
- **진행 이동**: 1~5장 × 단계(처음부터 / 임무 시작 / 임무 완료 / 비석 완료 / 수련 완료 / 보스 처치)로 바로 이동, 장에 맞는 레벨·무기 자동 맞춤, 엔딩 보기
- **바로 체험**: 일반 전투·보스전·그림자 장수전·외줄 수련을 진행 상황 변화 없이 연습
- **시연·난이도**: 난이도(쉬움/보통/어려움), 무적 모드(이 기기만), 회복·도구·냥 지급
- **문제 관리**: 문제 추가·고치기·삭제(장 지정 또는 모든 장, 보기 2~4개, O/X), **엑셀·CSV 템플릿 업로드**, 여러 문제 붙여넣기, 출제 방식(섞어서 / 선생님 문제만), 기본 문제 목록 보기 — 추가한 문제는 **다음 필살기에서 바로 출제**
  - **엑셀·CSV 템플릿으로 한꺼번에 올리기**: 「엑셀 템플릿 내려받기」 → 한 줄에 한 문제씩 작성 → 「파일 올리기」 → 미리보기에서 확인 → 「추가하기」(지금 문제에 더하기 / 모두 바꾸기)
    - 열 순서: `장 | 질문 | 보기1 | 보기2 | 보기3 | 보기4 | 정답 | 해설` (템플릿 파일: `assets/question-template.xlsx`, 「작성 방법」 시트 포함)
    - 장: 1~5 또는 `전체`(비우면 전체) · 정답: 보기 번호(1~4), 정답 보기의 글자, 또는 O/X(보기를 비우고 정답에 O/X만 쓰면 O/X 문제)
    - `.xlsx`(엑셀·구글 시트·한셀에서 저장), `.csv`(UTF-8·한글 CP949 모두) 지원, 회색 `(예시)` 줄은 자동으로 건너뜀, 최대 200문제
    - 잘못 적은 줄은 미리보기에 **몇 번째 줄이 왜 안 되는지** 빨갛게 표시 — 고쳐서 다시 올리면 됨
    - 「지금 선생님 문제 내보내기 (CSV)」로 받은 파일을 고쳐서 다시 올릴 수 있음(모두 바꾸기)
    - 템플릿은 `python3 tools/make_template.py`로 다시 만들 수 있음(openpyxl 필요)
  - 직접 붙여넣기: 엑셀에서 여러 줄을 복사해 그대로 붙여 넣거나, 한 줄에 한 문제씩 `장 | 질문 | 보기1 / 보기2 / 보기3 | 정답 번호 | 해설` (장은 1~5 또는 `전체`)
- **학생에게 보내기**: 문제·출제 방식·난이도·시작 장을 담은 **학생용 링크**(학생이 열면 그 기기에 바로 적용) 또는 설정 파일(.json) 내보내기·불러오기
- **학습 기록**: 이 기기의 정답률, 장별 정답률, 자주 틀린 문제 — 학생은 엔딩의 원정 기록 파일로 제출 가능

## 우리 반 연동판 (`class.html`)
교사가 문제를 넣거나 고치면 **같은 반 학생 화면에 실시간으로 반영**되는 버전입니다(서버 사용).
1. 교사: `class.html` → 교사용 → 「우리 반 연결」 → **반 비밀번호**를 정하고 **새 반 만들기** → 반 코드(6글자)가 생김
2. 학생: `class.html` 첫 화면에 반 코드 입력, 또는 교사가 복사해 준 입장 주소(`class.html?class=반코드`)로 접속
3. 교사가 「문제 관리」에서 문제를 추가·고치·삭제(템플릿 파일 업로드 포함)하거나 난이도·시작 장을 바꾸면 자동 저장 → 학생 화면에 알림과 함께 반영(새 문제는 다음 필살기에서 먼저 출제)
- 다른 기기에서 같은 반을 고치려면 「이미 만든 반에 다시 연결」에 반 코드와 반 비밀번호 입력
- 서버(Supabase)에는 **반 코드별 문제·출제 방식·난이도·시작 장만** 저장되고, 학생 이름·기록 같은 개인정보는 저장하지 않습니다. 반 비밀번호는 해시로만 보관됩니다.
- 실시간 연결이 막힌 학교 망에서도 30초마다 다시 확인해 반영합니다.
- 서버 구성: Supabase 프로젝트 `7guwol7-max's Project`의 `rpg_class_sets`·`rpg_class_keys` 테이블과 `rpg_save_class`·`rpg_check_class` 함수
- `class.html`은 `python3 build.py`가 `index.html`로부터 만들어 냅니다(직접 고치지 말 것)
