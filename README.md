# 우리말 수련기

6학년 국어 4단원 「소중한 우리말」의 낱말 30개(고유어·한자어·신조어 각 10개)를 익히는 **턴제 퀴즈 RPG**입니다.
까치 수련생 **가람**이 되어 고유어 숲, 한자어 서원, 신조어 저잣거리의 지킴이를 이기고 「우리말 겨루기 대회」 장원에 도전합니다.
낱말 뜻을 바르게 고르면 공격이 되고, 틀리면 정답과 뜻을 바로 보여 줍니다.

- 그림(픽셀 아트)과 소리(효과음·배경 음악)는 모두 코드로 직접 만들었습니다. 외부 파일, 인터넷 연결, 설치가 필요 없습니다.
- 진행 상황은 브라우저에 자동 저장됩니다. (저장이 막힌 환경에서도 게임은 할 수 있습니다.)
- 다 깨는 데 20~30분 정도 걸립니다.

## 실행 방법

`index.html` 파일을 더블클릭해서 크롬, 엣지, 웨일, 사파리 같은 브라우저로 열면 바로 시작됩니다.
태블릿에서는 폴더를 웹 서버(예: 학교 홈페이지, GitHub Pages)에 올려 주소로 여는 것이 가장 편합니다.

## 조작 방법

| 하는 일 | 키보드 | 마우스·터치 |
| --- | --- | --- |
| 걷기 (마을) | 방향키 또는 W A S D | 화면의 방향 버튼, 또는 가고 싶은 곳을 누르기 |
| 고르기 / 말 걸기 / 다음 대사 | Enter, Space, Z | 메뉴나 대화창 누르기, 「확인」 버튼 |
| 취소 / 마을 메뉴 | Esc, X | 「메뉴」 버튼 |
| 퀴즈 보기 고르기 | 1 2 3 4 (또는 방향키 + Enter) | 보기 누르기 |
| 힌트 부적 쓰기 (퀴즈 중) | H | 「힌트 부적 쓰기」 버튼 |
| 소리 켜기/끄기 | M | 오른쪽 위 「소리」 버튼 |

## 게임 흐름

1. **마을**: 여관(쉬기), 상점(약초·꿀떡·힌트 부적·장비), 수련장(다치지 않는 연습 퀴즈와 풀이), 서당(오답 수첩)이 있습니다.
2. **세 지역**: 고유어 숲 → 한자어 서원 → 신조어 저잣거리 순서로 열립니다. 탐색에서 3번 이기면 지킴이(보스)에게 도전할 수 있습니다.
3. **전투**: 공격(퀴즈), 기술(10초 안에 맞히면 큰 피해), 도구, 도망. 연속으로 맞히면 공격이 점점 세집니다. 보스가 힘을 모으면 「방어 퀴즈」를 맞혀 막을 수 있습니다.
4. **우리말 겨루기 대회**: 30개 낱말에서 골고루 나오는 3경기(1회전·2회전·결승전)를 이기면 엔딩과 수련 기록(정답률, 낱말 숙련도)이 나옵니다. 엔딩 뒤에도 계속 놀 수 있습니다.

져도 진행은 사라지지 않습니다. 마을로 돌아와 HP가 회복되고, 돈만 조금 줄어듭니다.

## 문제 바꾸기

문제는 `js/quizData.js` 한 파일에 들어 있습니다. 각 문제는 이런 모양입니다.

```js
{"id": 1, "cat": "goyu", "word": "시나브로", "choices": ["한꺼번에 갑자기", "모르는 사이에 조금씩", "아주 천천히 걷는 모양", "몹시 서두르는 모양"], "answer": 1},
```

- `id`: 문제마다 다른 번호 (바꾸면 그 낱말의 학습 기록이 새로 시작됩니다)
- `cat`: 분류 — `goyu`(고유어), `hanja`(한자어), `sinjo`(신조어). 각 지역은 자기 분류의 문제만 냅니다.
- `word`: 낱말
- `choices`: 보기 4개 (화면에는 매번 순서를 섞어서 보여 줍니다)
- `answer`: 정답 보기의 순서 번호 — **0부터 셉니다** (첫 번째 보기가 0, 두 번째가 1 …)

정답 보기의 글이 그대로 「뜻」으로 오답 수첩과 풀이에 나옵니다. 각 분류에 문제가 4개 이상 있으면 몇 개든 괜찮습니다.

## 파일 구성

```
index.html        게임 화면
css/style.css     글자·창 모양
js/quizData.js    문제 30개
js/engine.js      화면 맞춤, 게임 루프, 입력, 저장
js/audio.js       효과음·배경 음악 (WebAudio 합성)
js/art.js         캐릭터·배경 픽셀 아트
js/data.js        적, 도구, 장비, 기술, 지역 자료
js/ui.js          대화창, 메뉴, 퀴즈 창
js/quiz.js        낱말 기록과 문제 고르기
js/town.js        마을과 시설
js/battle.js      전투
js/main.js        타이틀, 이야기, 지역, 대회, 엔딩
```
